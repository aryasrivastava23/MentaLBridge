# 🧠 MentalBridge — Student Stress Analysis & Prediction

An interactive predictive analytics project focused on exploring student stress indicators using Python, Exploratory Data Analysis (EDA), data visualisation, and machine learning classification.

## 📌 Project Overview

MentalBridge explores patterns in student stress-related indicators and demonstrates how data analysis and machine learning can be used to study different stress categories.

## 🎯 Objectives

- Explore student stress-related data.
- Perform Exploratory Data Analysis (EDA).
- Understand relationships between different indicators.
- Apply machine learning classification algorithms.
- Visualise patterns and model evaluation results.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Visualisations

The notebook includes visualisations such as:

- Age and gender distribution
- Stress indicator distributions
- Anxiety vs. sleep analysis
- Academic overload analysis
- Correlation heatmap
- Confusion matrices
- Model accuracy comparison

## 🤖 Machine Learning Models

- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Random Forest

## 🚀 How to Run

1. Clone this repository.
2. Open `dataset.ipynb` using Jupyter Notebook or Google Colab.
3. Install the required Python libraries.
4. Make the dataset available at the file path referenced in the notebook.
5. Run the notebook cells sequentially.
